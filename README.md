# Data Science Educational Notes

This repository contains a collection of educational notebooks and lecture-style materials
created during my university studies.

The content focuses on core data analysis and preprocessing concepts,
with practical examples implemented in Python using Pandas and NumPy.

## Contents

### Pandas Fundamentals
- Series and DataFrame data structures
- Indexing and slicing
- Grouping, aggregation, and reshaping
- Reading and writing data
- Basic data visualization

### Handling Missing Values
- Types of missing data (MCAR, MAR, MNAR)
- Deletion techniques
- Simple imputation (mean, median, mode)
- Advanced imputation methods (KNN, regression-based)
- Time-series techniques (forward fill, backward fill, interpolation)

These materials are intended as learning notes and reference examples.
